    🖥️ Infraestructura tecnológica
    Frontend: HTML5 + CSS3 + JavaScript ES2022 — GitHub Pages (CDN global, 99.9% uptime)
    Base de datos: Supabase (PostgreSQL 15) — tablas: usuarios, canciones, interacciones
    Recomendaciones guardadas: campos recomendacion1 y recomendacion2 en tabla usuarios
    Búsqueda por voz: Web Speech API (SpeechRecognition) — idioma es-ES
    Visualizador de audio: Web Audio API (AnalyserNode) con barras animadas en tiempo real
    IA en cliente: Algoritmos JavaScript puro (KNN, J48, recursividad — sin dependencias ML externas)
