👥 Filtrado colaborativo
Encuentra usuarios con gustos similares al tuyo y descubre canciones que ellos aman pero tú aún no conoces.
Algoritmo KNN (K-Nearest Neighbors): Se mide la similitud entre usuarios contando canciones en común.
similitud(u,v) = |likes_u ∩ likes_v| / min(|likes_u|, |likes_v|)
Los 3 vecinos más cercanos aportan sus canciones favoritas que tú aún no has escuchado.

🌳 Árbol de decisión J48
Un clasificador supervisado entrenado con todos los historiales de interacción predice si una canción te gustará.
Atributos: energía, bailabilidad, popularidad, género.
Clase objetivo: like (1) / no like (0).
Regla de clasificación: Score ≥ 4 puntos → recomendar. Se acumula puntuación según si cada atributo supera la media aprendida del historial de likes del usuario.

🔄 Playlist recursiva
Desde tu último like, la función recursiva encadena canciones similares por género, energía y bailabilidad hasta una profundidad de 8 pasos.
Función recursiva:
generarPlaylist(cancion, profundidad, visitados) →
  [siguienteCancion, ...generarPlaylist(siguiente, profundidad-1, visitados+{siguiente})]
Caso base: profundidad = 0 o no hay candidatos → retorna [].

🖥️ Infraestructura tecnológica
Frontend: HTML5 + CSS3 + JavaScript ES2022 — GitHub Pages (CDN global, 99.9% uptime, gratuito)
Base de datos: Supabase (PostgreSQL 15) — tablas: usuarios, canciones, interacciones
Autenticación: Sesiones propias con hash en Supabase (filas RLS por usuario)
Audio: Archivos locales en carpeta /audios/ — servidos por GitHub Pages CDN
IA en cliente: Algoritmos JavaScript puro (sin dependencias ML externas)
